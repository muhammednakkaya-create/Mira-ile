MİRA İLE ÖĞRENİYORUM - BAŞLANGIÇ PROJESİ

Bu proje Expo / React Native ile hazırlanmıştır.
İlk sürümde:
- Harf ve sayı ekranı (parmakla çizim alanı)
- Türkçe sesli yönlendirme (Expo Speech)
- Şekil ve renk tanıtımı
- Yıldız sayacı
- Uygulama simgesi (assets/icon.png)

APK henüz derlenmiş değildir. Bu bir kaynak proje paketidir.

Expo ile açmak için:
1. ZIP dosyasını bir Expo projesi olarak yükleyin/açın.
2. Bağımlılıkları kurun.
3. Expo üzerinden Android'de test edin.
4. EAS Build ile APK oluşturun.

Not: Bu ilk prototipte çizim hareketi algılanır ve deneme sonunda yıldız verilir;
harfin konturuna ne kadar uyulduğunu ölçen hassas değerlendirme henüz eklenmemiştir.
